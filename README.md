# CalculatorGUI

A simple and user-friendly calculator application with a graphical user interface (GUI).  
Supports basic arithmetic operations like addition, subtraction, multiplication, and division.  
Built to demonstrate GUI development and event-driven programming concepts.

---

## Features
- Perform addition, subtraction, multiplication, and division
- Clean and intuitive GUI for easy use
- Handles basic input validation
